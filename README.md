# Русский перевод для Gelly 🎵

[![Русский язык](https://img.shields.io/badge/Перевод-Русский-blue)](https://github.com/yourusername/gelly-ru-translation)

Полный перевод интерфейса музыкального плеера **Gelly** на русский язык.

## Что переведено

- ✅ Основной интерфейс
- ✅ Настройки воспроизведения
- ✅ Очередь треков
- ✅ Управление плейлистами
- ✅ Системные сообщения и уведомления
- ✅ Горячие клавиши

## Установка

1. Скачайте файл `ru.json`
2. Поместите его в папку `locales/` в директории Gelly
3. Перезапустите приложение
4. Выберите русский язык в настройках

## Как использовать

Если вы разработчик Gelly, добавьте `ru.json` в папку `locales/` и обновите список языков.
