## Installation / Установка

**English:**
1. Download the `ru.json` file
2. Place it into the `locales/` folder in the Gelly directory
3. Restart the application
4. Select Russian in the settings

**Русский:**
1. Скачайте файл `ru.json`
2. Поместите его в папку `locales/` в директории Gelly
3. Перезапустите приложение
4. Выберите русский язык в настройках

**Русский:** Если вы разработчик Gelly, добавьте `ru.json` в папку `locales/` и обновите список языков.
